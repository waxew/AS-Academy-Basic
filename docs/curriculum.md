# نقشه جامع دوره Basic

Basic پیش‌نیاز مشترک همه دوره‌های زبان‌محور AS Academy است و از چهار سطح تشکیل می‌شود.

## 1. مبانی

سواد رایانه و سیستم‌عامل؛ شاخه‌ها و بازار کار؛ منطق و حل مسئله؛ الگوریتم؛ فلوچارت؛ شبه‌کد؛ متغیر و نوع داده؛ عملگر؛ ورودی/خروجی؛ شرط؛ حلقه؛ تابع.

خروجی این سطح: کاربر بتواند یک مسئله کوچک را تحلیل، به الگوریتم تبدیل و بدون وابستگی به Syntax یک زبان، مسیر حل را توضیح دهد.

## 2. مقدماتی

آرایه و مجموعه؛ رشته؛ تاریخ و زمان؛ مدیریت خطا؛ فایل؛ JSON/CSV/XML؛ ترمینال؛ Git/GitHub؛ Branch/Merge/PR؛ Debugging؛ Testing مقدماتی؛ Documentation و Commenting.

خروجی این سطح: کاربر بتواند یک پروژه کوچک را سازمان‌دهی، نسخه‌بندی، دیباگ و تست مقدماتی کند و داده را در قالب‌های رایج بخواند/بنویسد.

## 3. پیشرفته

OOP؛ Functional Programming؛ Recursion؛ Data Structures؛ Search/Sort؛ Complexity؛ Memory Management؛ Testing پیشرفته؛ Clean Code؛ Refactoring؛ SOLID؛ Design Patterns.

خروجی این سطح: کاربر بتواند درباره ساختار، هزینه الگوریتم، کیفیت طراحی و Trade-offهای راه‌حل استدلال کند.

## 4. تخصصی و بازار کار

Software Architecture؛ Dependency Management؛ Versioning؛ Security؛ Code Review؛ Agile/Scrum/Kanban؛ CI/CD؛ Open Source؛ Portfolio؛ Resume؛ Technical Interview.

خروجی این سطح: کاربر آماده ورود آگاهانه به یک مسیر تخصصی و اجرای استانداردهای پایه مهندسی نرم‌افزار باشد.

## گسترش هر فصل

فصل‌های بالا به بیش از 100 درس نهایی شکسته خواهند شد. هر فصل می‌تواند Lesson، Example، Exercise، Quiz، Exam، Flashcard، Glossary و Project مستقل داشته باشد. تعداد محتوا معیار تکمیل نیست؛ کیفیت آموزشی و پوشش اهداف یادگیری معیار اصلی است.
