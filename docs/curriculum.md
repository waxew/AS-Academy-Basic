# نقشه جامع دوره Basic

Basic پیش‌نیاز مشترک همه دوره‌های زبان‌محور AS Academy است و مسیر کامل آن در چهار سطح اصلی ساخته شده است. این دوره قرار نیست Syntax یک زبان خاص را تکرار کند؛ هدف آن آموزش منطق برنامه‌نویسی، ابزارهای توسعه و اصول مهندسی نرم‌افزار به‌صورت مستقل از زبان است.

## وضعیت فعلی

- 4 سطح اصلی
- 39 فصل
- 157 درس واقعی
- 155 تمرین
- 43 Quiz با 222 سؤال
- 14 پروژه مرحله‌ای
- 147 مدخل Glossary
- 56 Flashcard مفهومی در چهار Deck
- 16 منبع رسمی و مرجع
- آزمون جامع هر سطح و Final Capstone کل دوره

ترتیب Curriculum در نسخه `0.2.0` تثبیت شده است. نسخه Course/Host `0.3.0` عمق یادگیری، Flashcard، Glossary و Reference را اضافه می‌کند و ترتیب سرفصل‌ها را تغییر نمی‌دهد.

## 1. مبانی — Fundamentals

موضوعات:

سواد رایانه و سیستم‌عامل؛ شاخه‌ها و بازار کار؛ منطق و حل مسئله؛ الگوریتم؛ فلوچارت؛ شبه‌کد؛ متغیر و نوع داده؛ عملگر؛ ورودی/خروجی؛ شرط؛ حلقه؛ تابع.

وضعیت:

- 10 فصل
- 41 درس
- تمرین و Quiz فصل
- آزمون جامع سطح
- پروژه‌های مرحله‌ای و Capstone مبانی
- Deck مرور Fundamentals

خروجی یادگیری:

کاربر بتواند یک مسئله کوچک را تحلیل کند، آن را به زیرمسئله‌ها بشکند، الگوریتم و Pseudocode بسازد، جریان داده و کنترل را توضیح دهد و بدون وابستگی به Syntax یک زبان مسیر حل را طراحی کند.

## 2. مقدماتی — Beginner

موضوعات:

آرایه و Collection؛ String و Unicode؛ Date/Time؛ مدیریت خطا؛ فایل و Stream؛ JSON/CSV/XML؛ Terminal و Shell؛ Git/GitHub؛ Branch/Merge/Pull Request؛ Debugging؛ Testing مقدماتی؛ Documentation و Commenting.

وضعیت:

- 12 فصل
- 48 درس
- تمرین‌های داده، فایل، Git، Debugging و Test
- آزمون‌های فصل و آزمون جامع سطح
- پروژه Import/Report مهندسی‌شده
- Deck مرور Beginner

خروجی یادگیری:

کاربر بتواند داده را در ساختارها و قالب‌های متداول مدیریت کند، پروژه کوچک را در Git سازمان دهد، خطا را بازتولید و دیباگ کند، Unit Test بنویسد و مستندات قابل استفاده برای پروژه ایجاد کند.

## 3. پیشرفته — Advanced

موضوعات:

OOP؛ Functional Programming؛ Recursion؛ Data Structures؛ Search/Sort؛ Complexity؛ Memory Management؛ Testing پیشرفته؛ Clean Code؛ Refactoring؛ SOLID؛ Design Patterns.

وضعیت:

- 11 فصل
- 44 درس
- تمرین‌های طراحی، Data Structure، Algorithm و Refactoring
- آزمون‌های فصل و آزمون جامع Advanced
- چند پروژه مهندسی و Capstone پیشرفته
- Deck مرور Advanced

خروجی یادگیری:

کاربر بتواند درباره Abstraction، ساختار داده، انتخاب الگوریتم، Time/Space Complexity، Memory، Testability، Design Principle و Trade-offهای طراحی استدلال کند و یک کد Legacy را با Safety Net به ساختار قابل نگهداری تبدیل کند.

## 4. تخصصی و بازار کار — Specialist

موضوعات:

Software Architecture؛ Dependency Management؛ Semantic Versioning؛ Security و Threat Modeling؛ Code Review؛ Agile/Scrum/Kanban؛ Issue Tracking؛ CI/CD؛ Open Source؛ Portfolio؛ GitHub Profile؛ Technical Resume؛ Technical/Behavioral/Coding Interview.

وضعیت:

- 6 فصل
- 24 درس
- تمرین‌های معماری، امنیت، Review، Delivery و Career
- آزمون جامع Specialist
- پروژه Portfolio/Resume
- Final Capstone کل Basic
- Deck مرور Specialist

خروجی یادگیری:

کاربر بتواند یک پروژه را با مرزهای معماری، Version/Dependency policy، کنترل‌های امنیتی، Workflow تیمی، CI/CD، مستندات Release و شواهد Portfolio تحویل دهد و از تصمیم‌های فنی خود در مصاحبه دفاع کند.

## ساختار استاندارد درس

درس‌های Basic بر اساس نیاز موضوع از این اجزای استاندارد ساخته می‌شوند:

1. هدف درس و خروجی مورد انتظار
2. پیش‌نیاز
3. توضیح ساده و شهودی
4. توضیح تخصصی و Contract دقیق
5. مثال پایه
6. مثال واقعی
7. نکات مهم و Edge Caseها
8. اشتباهات رایج
9. تمرین مرحله‌ای
10. تمرین مستقل
11. Hint
12. Solution و Explanation
13. Quiz
14. Challenge
15. Project link در درس‌های مناسب
16. Summary
17. Glossary و اصطلاح فارسی/انگلیسی
18. Flashcard برای مفاهیم مهم
19. Reference رسمی در موضوعات استاندارد/امنیتی/ابزاری
20. سؤال مصاحبه در موضوعات مناسب

همه Lessonها الزاماً تمام 20 بخش را به‌صورت مصنوعی تکرار نمی‌کنند؛ انتخاب Blockها بر اساس هدف آموزشی انجام می‌شود.

## چرخه یادگیری

```text
Learn -> Example -> Practice -> Quiz -> Challenge -> Project -> Exam -> Review
```

Review از نسخه `0.3.0` فقط یک متن خلاصه نیست؛ Flashcardهای Course توسط `AS-Academy-Core 1.1.0` با Spaced Review، Rating و موعد مرور بعدی مدیریت می‌شوند.

## ارزیابی

لایه‌های ارزیابی هدف:

- Micro Quiz داخل مسیر یادگیری
- Lesson/Topic Check
- Chapter Quiz
- Level Exam
- Final Comprehensive Exam
- Exercise عملی
- Project milestone و Acceptance Criteria
- Final Capstone
- Review سؤال‌های اشتباه و Weak Topic در فاز بعدی
- Placement Test در فاز بعدی

## Final Capstone

پروژه نهایی `Personal Operations Manager` باید مفاهیم کل دوره را در یک تحویل مهندسی‌شده یکپارچه کند:

- Scope و Acceptance Criteria
- Data Model و Algorithm
- Architecture و Dependency Direction
- Storage، Migration، Backup/Restore و Import/Export
- Threat Model و Security Review
- Git/Issue/Branch/Pull Request
- Unit/Property/Integration/E2E/Regression Testing
- CI/CD و Release Artifact
- README، Changelog و ADR
- Performance/Complexity/Memory Review
- Code Review
- Portfolio Case Study
- Mock Technical Interview Defense

## مسیر توسعه بعدی محتوا

پوشش سرفصل اصلی دیگر مسئله پروژه نیست. تمرکز بعدی روی افزایش کیفیت سنجش و مرور است:

1. Weak Topic / Wrong Answer Review Engine در Core
2. Placement Test و تعیین سطح
3. افزایش Question Bank در سطح Lesson و Chapter
4. Rubric دقیق‌تر پروژه‌ها و Capstone
5. Challenge Exerciseهای بیشتر
6. Diagram و Assetهای بصری
7. گسترش Flashcard از 56 کارت هسته‌ای به پوشش granular درس‌های کلیدی
8. منابع رسمی بیشتر برای فصل‌های مهندسی نرم‌افزار
9. بانک بزرگ‌تر سؤال مصاحبه و Scenarioهای Design/Debugging

هر قابلیت reusable این مسیر باید در `AS-Academy-Core` ساخته شود و این Repository فقط محتوای اختصاصی Basic را نگه دارد.
